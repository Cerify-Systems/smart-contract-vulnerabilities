# Contracts

## Original Contract Availability

The vulnerable Permission Management contract exploited during the Transit Swap attack was **not verified on-chain**, and its original Solidity source code has **not been publicly released**.

Multiple independent security analyses explain that researchers investigated the incident by **decompiling the deployed bytecode**, as the original source code was unavailable.

To maintain the accuracy and integrity of this repository, no reconstructed or unofficial contract source has been included in this directory.

Readers interested in the implementation details should refer to the technical analysis and the referenced security reports in the `sources/` directory.
